## Legenda de Status Geral

- **EM INVESTIGAÇÃO:** Fase 1 ativa
- **EM PLANEJAMENTO:** Fase 2 ou 3 ativa
- **EM IMPLEMENTAÇÃO:** Fase 4 ativa
- **EM VALIDAÇÃO:** Fase 5 ativa
- **DOCUMENTANDO:** Fases 6-7 ativas
- **CONCLUÍDA:** Todas as fases aprovadas
- **PAUSADA:** Trabalho interrompido (anotar motivo no PROGRESS.md da feature)
- **ARQUIVADA:** Feature descartada

## Como usar

Para retomar qualquer feature, abra o `PROGRESS.md` correspondente. Ele contém as regras obrigatórias de operação, o contexto completo e o status de cada fase.
